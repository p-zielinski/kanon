# How the code was built

This file replaces the agent prompt dumps `PROMPTS.md`, `PROMPTS_V2.md`, and `PROMPTS_V2.1.md`. Each prompt was one session. The next prompt assumed the previous tests were green. The repeated instruction in every prompt was: read the plan, do not download weights, write the listed tests first and see them fail, then write the code, then run `pytest -q` with the v1 tests still green. That boilerplate is not copied below. What each prompt uniquely required is.

The v1 plan is [v1-plan.md](v1-plan.md). The v2 plan is [v2-plan.md](v2-plan.md). The closed run is [v2.1-result.md](v2.1-result.md).

## v1, twelve sessions

Common frame: parameters from the v1 table, no natural-language channel, PyTorch installed from [SETUP.md](SETUP.md) with no separate permission, no model download in any prompt.

1. Skeleton only. Create the venv, CPU torch, pytest, `requirements.txt` with the random-init comment, empty modules from the plan's repository map, and `tests/test_smoke_env.py` checking `nn.Linear(8, 8)` has weight shape `(8, 8)`. No parser, network, or round loop. Recorded result: Python 3.12, torch 2.14.1, pytest 9.1.1, 1 passed.

2. `language.py` and `reduce.py` only. Successor of two zeros is 2. Predecessor of zero is 0. The two `if0` examples in the prompt were stated as 0 and 1 in an order that takes the else branch at zero. That order makes the addition definition fail to return 5, and the same prompt requires 5, so zero takes the first branch. `(self ...)` outside `def` is a parse error. `(num 4)` in a `def` body is a parse error and in a `break` argument is legal. Fuel 256 ends runaway recursion with `fuel`. A term over 4096 nodes ends with `memory`. Polish text and a Python-style comment do not parse. Token list exactly as in the plan. Max arity 3. Slots `f0`-`f31`.

3. `tasks.py`. A seed builds a hidden term, 5 public pairs on inputs 0..6, and 16 audit pairs on 0..10, disjoint from the public set. Depth 1 is only identity, `succ`, `pred`, and constants 0, 1, 2. Depth 2 adds composition and one primitive recursion. Depth 3 with an empty canon adds only a deeper composition of primitives. `build_holdout(seed)` stores 50 tasks on depths 1..4 and is stable for the same seed. The object an agent may see has no hidden-term field. Two runs at seed 0 match. Seed 1 differs. Observation serialization has no field name `hidden`.

4. `canon.py`. An entry needs the def, the public pairs, 16 audit pairs, and the round. `last_used_round` updates when a solution contains `(call slot ...)`. After 12 rounds without a call the slot returns to the pool and the def is absent from the replay export. Every 4 rounds the oldest entry is reduced on its audit pairs; a mismatch removes it. The cemetery stores def, input, def result, target result, and round. The breaker export has the input and the mismatch, not the target term. Cap 32 entries. A 33rd definition without expiry is a refusal, not a silent overwrite.

5. `roles.py`. Round `r`: author `r%4`, breaker `(r+1)%4`, user `(r+2)%4`, outsider `(r+3)%4`. Over 8 rounds each agent holds each role twice. A slot parser accepts only its own shape. A wrong shape, including Polish text and a def with `(num k)` in the body, is the token `[ABS]` with no explanation. Author drafts `(draft (def ...))`. User and outsider draft `(draft expr)`. `propose`, `use`, and `solve` before the first draft are rejected. A fifth draft is rejected. The draft reply is `[TRY]` and five public results, `(num k)` or `(err)`, with no audit pairs. Author sees the canon, public pairs, and one free slot. Breaker also sees the candidate body. User sees their pairs and the candidate slot. The outsider does not see a rejected body or the hidden term.

6. `sample.py`. Uniform over legal productions, 64-token cap, seed-stable. Author body uses `zero`, `succ`, `pred`, `if0`, `var`, `self`, and `call` only to slots present in the canon. No `(num k)` in a body. `propose` only after at least one `[TRY]`. Breaker can say `(abstain slot)` or `(break slot (num k) ...)` with `k` in 0..10, and does not draft. User messages call the named candidate. Outsider messages call only canon slots. Fifty samples of each role parse, on an empty canon and on a canon that contains `f0`. No author sample contains `num`. The sampler must stand alone because the first rounds run at epsilon = 1.

7. `model.py`. Four decoders, seeds 0, 1, 2, 3. Agent 0 weights differ from agent 1. Source has no `load`, `from_pretrained`, `huggingface`, or `download`. Decoding takes a legal-production mask and puts probability 0 on an illegal production. Save and load of the four weight sets round-trips a tensor. No round loop. No weight file is downloaded.

8. `round.py`. Policy is the sampler at epsilon = 1. Tests inject messages. A `propose` without a prior draft does not open the audit. A draft that hits 5 public pairs and fails 16 audit pairs does not enter. A breaker input where def and target differ grows the cemetery and the candidate stays out. Abstain, plus a passing audit of 16, plus a user call whose solution passes, admits the candidate. A user solution without `(call slot ...)` keeps it out. An audit mismatch after abstain keeps it out. The outsider observation has no hidden term. Roles rotate by one after the round. No backward step yet. The round event is a JSONL object.

9. `update.py`. The tape holds accepted final messages and the current canon export. Drafts stay off, even when 5 public pairs matched. The cemetery reaches the breaker tape only as a confirmed kill. One AdamW step, lr `3e-4`, batch 32, clip 1.0, next-token cross entropy, sequences cut to 64. An empty tape skips the step and leaves weights bitwise equal. An artificial `(solve ...)` changes at least one weight of the agent who received it and not the other three. No second optimizer and no frozen reference copy as a running mode.

10. `baselines.py`. Solo: one network, 4 author proposals, admission only after 16 audit inputs, 4 learning steps, no breaker and no user, the same draft budget 1..4. Frozen weights: the outsider architecture, seed stored at the start, `step` never called. A test compares the weight hash before and after 5 evaluation rounds on the group canon and requires the same hash. No holdout curves in this prompt.

11. `run.py`, a short README, and the smoke. Loop: group round, then update. Every 10 rounds, score the holdout without `update`: group outsider per depth, solo, frozen outsider on the group canon, canon size, cemetery size, breaker-kill rate, audit-only kill rate, epsilon. Files `runs/<seed>/events.jsonl`, `metrics.csv`, and a canon snapshot. Holdout is built once before round 0 from a seed independent of the round seed. Depth starts at 1, grows on the 0.6 threshold, ceiling 4. Smoke: 20 rounds, seed 0, CPU, exit 0, both log files exist, and observation objects in `events.jsonl` do not contain the hidden term. The README had to say there is no model-pull phase, torch lives in the venv, and an empty canon after smoke is not a machine error. Do not add a fifth breaker. If the false-pass rate appears, only record it. Recorded: 87 passed, then later fixes reached 100 passed.

12. Read-only compliance pass. Write matches and gaps to the handoff. Do not fix gaps in that session. Later sessions did fix them. The last v1 pass, after the outsider was moved to after `admit`, found no new gaps. The checklist that passed is the one in the v1 plan: no weight download, four weight sets, a step after the group round and after solo, no step on evaluation or on the frozen baseline, observation without the hidden term, `(num)` only in data, the rotation formula, canon entry only when breaker, audit, and user call all hold, expiry 12, bench every 4, epsilon floor 0.05, the network table, draft budget 1..4 before `propose` / `use` / `solve`, drafts only on public pairs, drafts absent from the tape, and the same budget on group, solo, and frozen weights.

A later small change, not one of the twelve prompts: one `python -m kanon.run` appends rounds to `runs/<seed>/resume.pt`, one round by default, and `--fresh` deletes the save and starts at round 0.

4. Shelf. An entry accepted on its domain gets a stable id and does not vanish after 12 rounds, even if it is called. 5. Survey to 16 tokens, no `self`, no `call`, shortest first, deterministic at equal length, stop when four families are down and never after 16 tokens. Inside one length, terms without `if0` come first, so a thicket of `if0` does not spend 60 seconds before `(pred (var 0))`. Do not enumerate every `if0` tree. Do not write shape R1.

6. Simple hole `S`, no term list. `(zero)`, `(var i)` for `i` below the arity, and one `succ` or one `pred` around `(zero)` or `(var i)`. The plan's sentence says 5 holes at arity 1 and 9 at arity 2. 7. Floor 2, shapes R1 and R2. Addition on pairs `0..6` closes the addition family. Bounded subtraction, `max(x-y, 0)`, lands on the shelf and does not close the floor by itself. Two successors are not addition. The first hit in shortest-first order is the one that stays, and the scan of that family stops. 9. Floors 3-8. There are no shapes C1 or C2. A composition of calls is not a floor. Floor 3 R1 multiplication on pairs `0..6`. Floor 4 N1 comparison, 1 when `x <= y`, else 0. 10. Tactic kernel. No Lean. `eval` compares both sides on the domain stated in the sentence.
